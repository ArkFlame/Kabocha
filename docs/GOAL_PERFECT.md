# GOAL: Kabocha is perfect: upstream-grade CI, vanilla-faithful, shipped and playable

Done only when every item is true with evidence. Never stop early, never ask; use .vendor/** and upstream Pumpkin as the reference and record precedent. Up to 20 native subagents in parallel, refill at once; workers never run cargo, the orchestrator batch-checks via scripts/cargo.sh.

1. UPSTREAM PARITY. `scripts/sync-upstream.sh` shows 0 behind Pumpkin-MC/Pumpkin master, hourly sync logged in docs/SYNC.md. Every upstream workflow job passes on our head: Spelling (typos), fmt, Run lints, Run release lints, Cargo Build/Test, Validate pumpkin-plugin-wit, Nix Flake build. Jobs gated by `github.repository == 'Pumpkin-MC/Pumpkin'` (Versioning, Sync WIT, release) are reproduced locally and documented, never silently skipped. `gh run list -R ArkFlame/Kabocha` is all green on the pushed commit.
2. GATES, exit 0, through scripts/cargo.sh: `cargo fmt --all --check`; `clippy --workspace --locked --all-targets --all-features -- -D warnings` and the same with `--release`; `test --workspace --locked --no-fail-fast` with every flaky test fixed or isolated (pathfinder test fails only under load); typos; `cargo deny`/audit; no new unwrap/panic; functions under 100 lines or an upstream-style `#[expect]`.
3. NO OPEN GAPS. docs/PARITY.tsv: every row is DONE with citation (path plus vanilla file:line) or open with a one-line reason. Fix every STILL OPEN row with a test that fails without the fix; unblock BLOCKED-DATA by extending assets/ and regenerating pumpkin-data (`cargo run --locked -p pumpkin-codegen`); give repeatedly blocked subsystems (entity sub-predicates, Breeze brain, push reaction, shelf shapes, last_hurt_mob) an owner slice. TRACKER.md, DONE.md, TODO.md, README stats regenerate from the TSV and match.

Differential tests against extracted vanilla data (loot, recipes, block states, collision shapes, chunk dumps, packet bytes) fail CI on any diff. `pumpkin-gametest` scenarios for fire, villagers, mob goals, redstone, fluids, shearing, bees. Re-verify every upstream-merge decision (bee goals, Shearable, item stacking) against vanilla.
5. ROBUSTNESS. Agent-driven bots join, move, build, fight, trade, disconnect for 30 minutes: no panic, tick p99 under 50 ms, bounded memory, no desync. Fuzz packet, NBT, anvil and datapack parsers; bound every network/disk/plugin allocation; WIT additive-only.

7. DELIVERY. Release `pumpkin` binary for linux x86_64 in dist/ with SHA256SUMS and commit hash; verified to start, load a world, accept a login and stop cleanly. Start it detached on a fresh world, confirm the port answers a status ping, and report public IP:port, LAN IP:port, version, commit and how to stop it. Keep it running.
