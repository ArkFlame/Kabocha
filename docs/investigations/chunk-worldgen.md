# World-generation stage coverage: Pumpkin vs decompiled vanilla

Verdict: MATCHES on stage order and seeding math; DIFFERS on feature-placement modifier coverage and on blending (implemented but unwired).
The core pipeline order (biomes -> density/noise + aquifers -> surface -> carvers -> features, with structure starts/references first) and the WorldgenRandom seed formulas (population/decoration, feature, large-feature, large-feature-with-salt) match vanilla exactly.
The gaps are confined to: three missing placement modifiers, an unwired Blender (so old-chunk height/density/biome blending and upgrade-only border ticks/carve filters never run), and two small ordering/selection differences.

## Verified matches

- Pipeline order: Pumpkin stages `Biomes -> StructureStart -> StructureReferences -> Noise -> Surface -> Carvers -> Features -> Lighting -> Spawn -> Full` (`crates/pumpkin-world/src/chunk_system/generation.rs:9-18`, `crates/pumpkin-world/src/generation/proto_chunk.rs:846-1059,1429`) mirror vanilla chunk statuses `STRUCTURE_STARTS -> STRUCTURE_REFERENCES -> BIOMES -> TERRAIN -> FEATURES -> ...` (`world/level/chunk/status/ChunkStatus.java:21-30`). Within terrain, vanilla runs `doFill -> buildSurface -> generateCarvers` (`NoiseBasedChunkGenerator.java:405-425`) and Pumpkin runs `populate_noise -> build_surface -> carve` (`proto_chunk.rs:1128,1250,carver/mod.rs:205`) — same ordering.
- Decoration seed: Pumpkin `WorldgenRandom::get_population_seed(seed, start_x, start_z)` (`crates/pumpkin-world/src/generation/proto_chunk.rs:1464-1465`; `crates/pumpkin-util/src/random/mod.rs:68-76`) = vanilla `setDecorationSeed` (`WorldgenRandom.java:44-51`), with `| 1` on both scale terms.
- Per-feature seed: `get_decorator_seed(population_seed, global_index, step)` = `population_seed + index + 10000*step` (`crates/pumpkin-util/src/random/mod.rs:95-99`; `proto_chunk.rs:1491-1494`) matches vanilla `setFeatureSeed` (`WorldgenRandom.java:53-56`; `ChunkGenerator.java:486-498`). The global index comes from the sorted `features_per_step` list (`feature_order.rs:121-167`), matching vanilla `FeatureSorter.StepFeatureData.indexMapping` (`ChunkGenerator.java:474-488`).
- Structure step seeding: `get_decorator_seed(population_seed, index, step)` with `index` counting structures in that step (`proto_chunk.rs:1573-1582,1654`) = vanilla `random.setFeatureSeed(decorationSeed, index, stepIndex)` (`ChunkGenerator.java:445-448`), and structures are processed before features within each step in both (`ChunkGenerator.java:444-467`; `proto_chunk.rs:1478-1487`).
- Large-feature seed: `get_large_feature_seed` (`crates/pumpkin-util/src/random/mod.rs:192-199`) = vanilla `setLargeFeatureSeed` (`WorldgenRandom.java:58-64`, `x*xScale ^ z*zScale ^ seed`). Salted variant `get_large_feature_with_salt` (`random/mod.rs:116-124`) = `setLargeFeatureWithSalt` (`WorldgenRandom.java:66-69`) and is used with the same argument order `(seed, salt, x, z)` for structure frequency reduction (`placement.rs:607-620`) and random-spread region seeds (`placement.rs:662-696`).
- Carver seeding and start-chunk test: `get_large_feature_seed(seed + index, carver_x, carver_z)` and `random.next_f32() <= probability` (`carver/mod.rs:257-266,383-395`) = vanilla `random.setLargeFeatureSeed(randomState.seed() + index, sourcePos.x, sourcePos.z)` and `carver.isStartChunk` (`NoiseBasedChunkGenerator.java:259-269`; `CaveWorldCarver.java:50-51`, `CanyonWorldCarver.java:28-29`). Carve radius 8, `protected_blocks_on_top = 7`, and mask range `minGenY+1 .. minGenY+genDepth-1-7` match (`carver/mod.rs:216,230-233`; `NoiseBasedChunkGenerator.java:240,243-245`).
- Carver kinds: only Cave and Canyon carvers exist in vanilla (`WorldCarverTypes.java`, `CaveWorldCarver.java`, `CanyonWorldCarver.java`) and Pumpkin dispatches exactly those two (`carver/mod.rs:235-236,267-292`); the nether uses the cave carver config, so no separate nether carver is missing.
- Surface rules: Pumpkin handles all rule kinds `Badlands/Bandlands, Block, Sequence, Condition, OreVein` (`surface/rule.rs:15-30`) and all material conditions `Biome, NoiseThreshold, VerticalGradient, YAbove, Water, Temperature, Steep, Not, Hole, AbovePreliminarySurface, StoneDepth` (`surface/mod.rs:305-343`), matching the vanilla `MaterialRules` registry (`material/MaterialRules.java:14-31`) and its condition constructors (`MaterialRules.java:54-102`).
- Aquifer types: Pumpkin provides `WorldAquiferSampler` (noise-based), `CarverAquiferSampler` and `SeaLevelAquiferSampler` for disabled aquifers (`aquifer_sampler.rs:52-63,221,816`) = vanilla `NoiseBasedAquifer`, carver path and `Aquifer.createDisabled` (`Aquifer.java:26-30,86-126`), including the 12-samples-per-position cache and `shouldScheduleFluidUpdate` signal.
- Feature ordering/sorting: `sort_features_per_step` builds a global dependency graph and stable order per dimension (`feature_order.rs:169-...`), matching vanilla `FeatureSorter`'s globally sorted per-step feature list used to assign the index that seeds each feature (`ChunkGenerator.java:415,474-488`).
