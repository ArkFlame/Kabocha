ServerLevel.getFreeMapId() calls getServer().getDataStorage().computeIfAbsent(MapIndex.TYPE).getNextMapId()
(ServerLevel.java:4372). MinecraftServer.getDataStorage() returns one server-wide SavedDataStorage rooted

(MapIndex.java:11,20-31). Pumpkin already matches this: Server::map_id is a single server-wide AtomicI32,
next_map_id() does fetch_add (first id 0, monotonic), and the value is persisted in level.dat
(world_info/anvil.rs:282-283 load, :371 save) and restored at server init (server/mod.rs:384).
Moving the counter into World for "per-dimension uniqueness" would break vanilla parity, so it is not applied.

behaviorally equivalent for normal play; changing it needs a new SavedData file in world/ (cross-crate, not required).
