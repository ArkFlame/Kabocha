## Result

FIXED. `world/explosion.rs` `Destroy`/`DestroyWithDecay` now calls the per-block `explode`
hook (vanilla `onExplosionHit`) before `drop_loot`/`set_block_state(AIR)`, so blast
reactions see the block still placed. To keep that faithful, added
`Explosion::can_trigger_blocks(&World)` mirroring `ServerExplosion.canTriggerBlocks`
(`TRIGGER_BLOCK` and, for a breeze wind charge, `mobGriefing`) and gated the
wind-charge-only hooks on it: `buttons.rs` (button press), `candles.rs` and
`candle_cakes.rs` (extinguish). Without the gate, moving the hook ahead of removal would
have extinguished candles on every destroy blast. Test:
`explosion::tests::only_wind_charge_explosions_can_trigger_blocks`.
