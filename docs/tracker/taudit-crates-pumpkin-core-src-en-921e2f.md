## Fixed in this audit
- Armor population ran HEAD -> FEET, so a mob always got a helmet and only sometimes boots. Vanilla iterates EquipmentSlot.values() (FEET, LEGS, CHEST, HEAD) and only rolls the early-stop chance after the first armored slot, i.e. feet are always present. Reordered ARMOR_TIERS + ARMOR_POPULATION_ORDER (equipment.rs:88-146, 549-577), added test armor_population_starts_at_feet_like_vanilla (equipment.rs:1133-1151). Commit fd5628698.
