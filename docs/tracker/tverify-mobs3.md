Tests: none added. The blaze damping, ghast spawn height, bee maluses and tag, wolf health, horse goal list and piglin baby speed all need a world or the attribute map and a target, so a pure test would only mirror the code. The wolf constant is a constant, which the rules forbid testing.

Risks: the bee and abstract horse goal removals change goal sets for every horse family and bee entity. Donkey and mule `registerGoals` were not checked and might add a random look. The bee FIRE malus maps to `DamageFire`, which follows the existing blaze mapping but is an assumption. The bee hive gap means bees never return to a hive, so the `ticks_without_nectar` nbt is inert.
